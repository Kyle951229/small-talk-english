# Small Talk · 英文自學網站

以每天 60 分鐘、全年 3,000 單字與聽說練習為主的個人自學網站。

- 365 天循序課程、198 組語塊、間隔複習與主動回想。
- 48 篇 British Council A1–B2 免費原站英聽連結；多輪深聽、復述、追問與隔日測驗。
- 既有合成英文課程音檔與內建替代聽力。
- 本機瀏覽器儲存、歷史紀錄、資料匯出及匯入。
- App 底部分頁、聚焦字卡、逐題測驗與三步驟英聽作業。
- 可加入主畫面的 PWA；全年文字與已快取的本站音檔支援離線使用，外站教材仍需連網。

## 使用

正式網站：[Small Talk 英文學習網站](https://kyle951229.github.io/small-talk-english/)

GitHub Pages 設為 main 分支根目錄即可部署。這是純靜態網站，不需安裝套件或 API 金鑰。

請閱讀 [使用說明](使用說明.md)、[英聽作業與來源](英聽作業與來源.md) 以及音檔、字庫授權說明。

## 學習紀錄

紀錄存在目前網址的瀏覽器儲存空間，沒有帳號或雲端同步。從本機轉到正式網址，請先在舊網站匯出備份，再到新網址匯入；上傳的專案不含你的個人學習紀錄。

## 範圍

一年自然聊天是練習目標，並非成果保證；仍需要持續投入與真人交流。錄音需要麥克風權限；語音辨識僅比對文字，作業口語採自我檢核，不提供 AI 語意或發音評分。原站聽力需連網另開頁面。
